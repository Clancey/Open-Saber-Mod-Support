# Fonts

`teko_medium` / `teko_bold` are bitmap (BMFont) conversions of the Teko typeface
by Indian Type Foundry, licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). The atlases are
were rendered from the upstream OFL font at 89 px and are
scaled fractionally by Godot's BMFont importer (`scaling_mode=2`).

The OFL allows the font to be used, modified and redistributed freely as long as
it is not sold by itself; the reserved font name "Teko" is not used for the
converted files.
