# Fonts

`teko_medium` / `teko_bold` are bitmap (BMFont) atlases rendered from the Teko
typeface by Indian Type Foundry, licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). They are generated by `tools/art/gen_fonts.py`,
which rasterises the upstream OFL variable font (weight axis 500 and 700) at
89 px into a 1024x1024 page, and are scaled fractionally by Godot's BMFont
importer (`scaling_mode=2`). Re-run that script to regenerate them.

The full license text is in `OFL.txt`. The OFL allows the font to be used,
modified and redistributed freely as long as it is not sold by itself; the
upstream release declares no Reserved Font Name.
